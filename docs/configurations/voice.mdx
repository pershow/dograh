---

Dograh platform supports ElevenLabs, OpenAI, Google, Azure Speech, Deepgram, Cartesia, Smallest AI, MiniMax, Sarvam, Rime, Inworld, Camb.ai, xAI, LMNT, Speechify, Qwen (DashScope), and Dograh TTS engines. There are some voices from the providers that we ship by default. You can refer to the providers API documentation to select a voice ID that's most relevant for your language requirement.

<Warning>
Voice providers receive the data needed to synthesize speech, such as generated text, selected voice, model settings, and request metadata. Review the provider's data processing, retention, model training, and regional hosting policies before using sensitive data.
</Warning>

For locally deployed or self-hosted TTS models, Dograh also supports Speaches, an OpenAI API-compatible server for speech generation.

If you don't find your favourite voice, you can always add the voice ID manually.

## Qwen (DashScope)

Select your **Qwen (DashScope)** provider connection for **TTS** in a **BYOK** model configuration. Use a DashScope API key and the realtime endpoint for the same region, as described in [Transcriber](/configurations/transcriber#qwen-dashscope).

The default model is `qwen3-tts-flash-realtime` with the `Cherry` voice. Choose a voice from the list or enter a voice ID supported by your model. Set **Language** to `Chinese` for Chinese speech or `Auto` for multilingual replies, and adjust **Speed** from 0.5 to 2.0. Dated realtime model versions can be entered as a custom model value.

See the [Qwen voice list](https://help.aliyun.com/en/model-studio/qwen-tts-voice-list) for additional voices.
