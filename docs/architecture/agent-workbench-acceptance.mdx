## 自动化验证

后端本次选定测试共 **110 项通过**，4 条已有依赖弃用警告；前端语音生命周期 **3 项通过**。

后端覆盖：

- Responses / Chat 路由、函数工具白名单、调用 ID 保留、上游失败不自动回退。
- 嵌套测试集 JSON Schema 的引用解析。
- DOCX、XLSX、文本、图片解析，Office 宏拒绝，超长文本标记。
- 仿真必须提供外部工具 / HTTP 预取 / 知识库夹具；真实引擎的工具与 MCP 开启路径被策略提前截断。
- 参数不匹配、错误、空回复不能算通过；断言只检查 Agent 发言及真实节点事件。
- 组织隔离、跨会话引用拒绝、幂等提交、取消后的租约保护、任务过期后的评测状态收敛。
- 草稿冲突拒绝、重复采用幂等、采用不自动发布、仿真运行不进入普通运行查询。
- 原工作流版本、文本对话、文本日志、文本闲置策略、OpenRouter 服务工厂回归。
- DashScope Qwen 的 Chat 参数与 developer 角色兼容仅影响对应连接。

前端覆盖麦克风授权失败、晚到的授权结果、组件卸载资源释放、候选/测试集/附件上下文更新。浏览器验收补充覆盖真实页面的配置切换、附件上传、草稿采用和原编辑器衔接。

复现自动化测试：

```bash
source venv/bin/activate
set -a
source api/.env.test
set +a
python -m pytest api/tests/test_agent_workbench* api/tests/test_workflow_versioning.py api/tests/test_workflow_text_chat.py api/tests/test_openrouter_llm_service_factory.py api/tests/test_text_chat_logs.py api/tests/test_text_chat_inactivity.py -q
```

在 `ui/` 目录运行：

```bash
npx tsc --noEmit
npm test -- src/components/agent-workbench/__tests__/useWorkbenchVoice.test.tsx
```
